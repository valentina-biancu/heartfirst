# HeartFirst Risk Atlas — Inflammation v1

This is the second focused module in the HeartFirst Risk Atlas series.

## What this version is

- A focused educational page about inflammation in cardiovascular risk context
- A module that reuses the HeartFirst Risk Atlas shell but adapts the interaction for the subject
- Uses an artery and plaque environment to show inflammatory signalling, immune-cell involvement, endothelial irritation, and plaque activation

## Subject-specific interaction

This page uses **Activity view** rather than Plaque's exploded view. That is deliberate: inflammation is better shown as signalling, glow, immune-cell movement, and plaque activation rather than as separated structural layers.

## Included interactions

- progression slider from quieter artery environment to higher inflammatory context
- play / pause
- labels on / off
- activity view toggle
- reset
- stage explanation panel
- product bridge CTAs
- light / dark mode toggle using the same `hf-theme` pattern as the HeartFirst Navigator page

## Medical boundary

This module is educational. It does not diagnose inflammation, predict plaque instability, interpret hs-CRP, or show what is happening in any individual body.
